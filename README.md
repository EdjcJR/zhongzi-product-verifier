# 中資商品／品牌驗證器（Zhongzi Product Verifier）

一套用於查證品牌或商品是否涉及「中資（中國資本）」的結構化驗證通則與工具。

目標：讓消費者「買得明白」，而非呼籲抵制。

---

## 最大貢獻者致謝

本專案的核心查證手法、證據標準、報告語氣與大量實際案例，全部來自 Threads 帳號 **@unmasking.chinese.capital（中資現形記）** 的細心整理與公開分享。

## 兩種使用方式

### 1. Grok 專用版（自動觸發）

把 `grok-skill/` 資料夾內容放入 Grok 的 skills 目錄後，系統會在使用者提到中資查證、品牌背景、上傳商品描述／照片時自動載入並執行驗證流程。

### 2. 通用版（任何 AI）

打開 `universal/UNIVERSAL-PROMPT.md`，把「核心指令」整段複製貼到 ChatGPT、Claude、Gemini、本地模型等作為 System Prompt 或 Instruction，然後提供商品資訊即可。

## 核心驗證通則摘要

1. 提取官方敘事（官網、包裝、廣告）
2. 查實際控制人與公司結構
3. 追溯收購／轉讓歷史
4. 查商標與註冊地
5. 檢視台灣代理結構
6. 資料／金流流向（連網產品與贊助平台）
7. 集團關聯釐清
8. 嚴格證據門檻（證據不足者不強行判定）

**範圍**：只查中國資本、中國品牌、假冒洋牌。純代工（MIC）不入列。

**報告原則**：中立、可驗證、不推薦替代品、不呼籲抵制。

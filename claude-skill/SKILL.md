# 中資商品／品牌驗證器（Zhongzi Product Verifier）

## 概要

依固定的搜尋與分析流程，查證品牌／商品的中國資本涉入程度。接受純文字，或從商品照片擷取出的文字。輸出簡短風險報告，附證據與信心程度。

**範圍**：只查中國資本、中國品牌、假冒洋牌。純代工（MIC）且無資本控制關係者不列入。

**目標**：讓消費者「買得明白」，不是呼籲抵制。

**來源致謝**：核心查證手法、證據標準、報告語氣與大量案例，皆來自 Threads 帳號 @unmasking.chinese.capital（中資現形記）的公開整理。本 skill 僅將其方法系統化。原始帳號：https://www.threads.com/@unmasking.chinese.capital
專案出處：https://github.com/EdjcJR/zhongzi-product-verifier（授權：MIT／CC-BY-4.0）

## 輸入處理

1. 使用者給照片：先讀出可見文字（品牌、型號、產地標示、包裝宣稱、通路），整理成實體摘要。
2. 使用者給文字：直接解析品牌、型號、官方宣稱與其他細節。
3. 只有在輸入稀疏到無法查證時（例如連品牌名都沒有）才追問，且一次只問一個問題。

## 標準查證流程（依序執行）

**執行方式**：用 web_search／web_fetch 實際查公開資料，不要憑記憶下結論。公司股權、收購、商標狀態會變動，每個關鍵事實都應有查到的來源與日期。

1. **提取官方敘事**：官網、包裝、廣告、創辦人說法（如「香港國際品牌」「創辦於加州」「法國軍隊御用」）。
2. **查實際控制人與公司結構**：母公司全名、註冊地（中國大陸／香港／台灣／海外）、主要股東或實際控制人及背景。查台灣商工登記（FindBiz）；必要時查中國企業信用公示系統（GSXT）或企查查、天眼查類來源。
3. **追溯收購／轉讓歷史**：時間、金額、對象。留意「先當代理，再入股控股」模式。區分控股與純財務投資。
4. **核對商標與網域**：特別針對宣稱歐美背景者，查 USPTO 等資料庫的原始登記人。
5. **檢視台灣市場結構**：台灣代理商是否為獨立台灣公司（有無股權關係）；momo、PChome、蝦皮、實體專櫃的銷售情況。
6. **資料與金流**（連網裝置、贊助平台）：隱私政策中的資料傳輸目的地與控制實體；贊助／支付平台的註冊地、準據法、金流商顯示名稱。
7. **集團關聯釐清**：列出同一控制人下的品牌；明確分開「同集團名稱但台灣代理獨立、無資本關聯」者。
8. **證據門檻**：只採公開可驗證資料。有線索但證據不足者排除或標為低信心。純中國製造（MIC）而無資本控制者不在範圍內。

## 報告格式

輸出簡短、適合手機閱讀的結構化報告：

- **品牌／商品**：名稱與型號
- **風險等級**：低／中／高／極高（或「證據不足」）
- **核心發現**：1–3 句
- **主要證據**：最強的公開事實（公司、控制人、收購、敘事落差）
- **台灣現況**：代理結構與販售情形
- **信心程度**：高／中／低＋簡短理由
- **主要來源**：實際用到的公開資料，並註明資料日期
- **結語**：「不是叫你抵制，只是讓你知道——買得明白就好。」（或等義的中立收尾）

不推薦替代產品。

### 選用：貢獻區塊

主報告後，可附一段讓使用者複製到公開管道（Threads、Discord、共編表單）的區塊：

```
【中資查證貢獻】
品牌：
風險等級：
核心發現：
主要來源：
查證日期：
```

## 通路快速模式

使用者只問銷售通路（尤其台灣 3C 通路）時，先參考 `references/channel-data.md` 的快照（資料日期 2026-10-08）。重點：Water3F 品牌 75%／商品 92.5%、智選家 70%／87.4%、先創 52.9%／83.8%、東城 47.6%／51.6%；商品層級比例通常高於品牌層級。

這是第二手統計快照，引用時須註明日期，並提醒使用者比例會變動、需重新查證。若使用者要的是特定品牌的結論，仍走完整流程。

## 額外規則

- 優先採用一手公開登記資料，而非二手評論。
- 各市場官網說法不一（台灣 vs 瑞典／美國）時，並列呈現落差。
- 涉及國資實體（如上海市國資委）時，註明其國有背景。
- 保持中立，絕不呼籲抵制。
- 證據不足時明講「證據不足，無法判定」，不要猜。
- 不確定或查不到的地方直接說，不要硬湊。

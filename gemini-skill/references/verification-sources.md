# 建議查核來源清單

進行資本結構與品牌背景查證時，請優先參考以下公開資料庫：

- **台灣**：
  - 經濟部商業發展署商工登記（FindBiz / 公司與商業登記公示資料查詢服務）
  - 經濟部投資審議司（投審司中資許可名冊）
- **中國大陸**：
  - 國家企業信用資訊公示系統（GSXT）
  - 商業查冊工具：企查查、天眼查、愛企查
- **香港**：
  - 香港公司註冊處網上查冊中心（ICRIS）
- **國際/商標**：
  - 美國專利商標局（USPTO）
  - 歐洲聯盟知識產權局（EUIPO）
  - 各市場官方網站、公開上市招股說明書（IPO Prospectus）、年報（Annual Reports）與隱私權政策條款（Privacy Policy）
